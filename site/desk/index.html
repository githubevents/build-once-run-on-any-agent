Build once, run on any agent

Most developers use AI the same way: open a chat, type a prompt, move on. The context disappears. The next step starts from scratch. Agent skills fix that. Andrea Griffiths builds them for her own recurring work: files any coding agent can run. Shishir Tewari builds them for a data engineering team at Procore, where a skill has to encode senior-engineer judgment and survive production. Different scale, same format. The file you write for yourself tonight is the same file that runs a team’s pipeline.

You will leave with a clear model for when to build a skill instead of writing another prompt.
